ชุดโครงการชุมชนที่สร้างขึ้นบน Nami

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Nami ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-nami](https://github.com/awesome-nami/awesome-nami) และ [nami.cafe](https://nami.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
