Nami integreres med din GitLab-arbejdsgang gennem din GitLab CI/CD-pipeline eller med GitLab Duo.

I begge tilfælde vil Nami køre på dine GitLab-løbere.

---

## GitLab CI

Nami fungerer i en almindelig GitLab-pipeline. Du kan bygge det ind i en pipeline som en [CI component](https://docs.gitlab.com/ee/ci/components/)

Her bruger vi en community-skabt CI/CD-komponent til Nami — [nagyv/gitlab-nami](https://gitlab.com/nagyv/gitlab-nami).

---

### Funktioner

- **Brug brugerdefineret konfiguration pr. job**: Konfigurer Nami med en brugerdefineret konfigurationsmappe, for eksempel `./config/#custom-directory` for at aktivere eller deaktivere funktionalitet pr. Nami påkald.
- **Minimal opsætning**: CI-komponenten sætter Nami op i baggrunden, du behøver kun at oprette Nami-konfigurationen og den indledende prompt.
- **Fleksibel**: CI-komponenten understøtter flere input til at tilpasse dens adfærd

---

### Opsætning

1. Gem din Nami-autentificering JSON som en filtype CI-miljøvariabel under **Indstillinger** > **CI/CD** > **Variabler**. Sørg for at markere dem som "Maskede og skjulte".
2. Tilføj følgende til din `.gitlab-ci.yml` fil.

   ```yaml title=".gitlab-ci.yml"
   include:
     - component: $CI_SERVER_FQDN/nagyv/gitlab-nami/nami@2
       inputs:
         config_dir: ${CI_PROJECT_DIR}/nami-config
         auth_json: $RSMRTK_AUTH_JSON # The variable name for your Nami authentication JSON
         command: optional-custom-command
         message: "Your prompt here"
   ```

For flere input og use cases [check out the docs](https://gitlab.com/explore/catalog/nagyv/gitlab-nami) for denne komponent.

## GitLab Duo

Nami integreres med din GitLab-arbejdsgang.
Nævn `@nami` i en kommentar, og Nami vil udføre opgaver i din GitLab CI-pipeline.

---

### Funktioner

- **Triageproblemer**: Bed Nami om at undersøge et problem og forklare dig det.
- **Ret og implementer**: Bed Nami om at løse et problem eller implementere en funktion.
  Det vil oprette en ny branch og rejse en Merge Request med ændringer.
- **Sikker**: Nami kører på dine GitLab-løbere.

---

### Opsætning

Nami kører i din GitLab CI/CD pipeline, her er hvad du skal bruge for at konfigurere det:

:::tip
Tjek [**GitLab docs**](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/) for opdaterede instruktioner.
:::

1.  Konfigurer dit GitLab-miljø
2.  Konfigurer CI/CD
3.  Få en API-nøgle til en AI-modeludbyder
4.  Opret en servicekonto
5.  Konfigurer CI/CD variabler
6.  Opret en flow-konfigurationsfil, her er et eksempel:

        <details>

    <summary>Flowkonfiguration</summary>

    ```yaml
    image: node:22-slim
    commands:
      - echo "Installing nami"
      - npm install --global nami-ai
      - echo "Installing glab"
      - export GITLAB_TOKEN=$GITLAB_TOKEN_NAMI
      - apt-get update --quiet && apt-get install --yes curl wget gpg git && rm --recursive --force /var/lib/apt/lists/*
      - curl --silent --show-error --location "https://raw.githubusercontent.com/upciti/wakemeops/main/assets/install_repository" | bash
      - apt-get install --yes glab
      - echo "Configuring glab"
      - echo $GITLAB_HOST
      - echo "Creating Nami auth configuration"
      - mkdir --parents ~/.local/share/nami
      - |
        cat > ~/.local/share/nami/auth.json << EOF
        {
          "anthropic": {
            "type": "api",
            "key": "$ANTHROPIC_API_KEY"
          }
        }
        EOF
      - echo "Configuring git"
      - git config --global user.email "nami@gitlab.com"
      - git config --global user.name "Nami"
      - echo "Testing glab"
      - glab issue list
      - echo "Running Nami"
      - |
        nami run "
        You are an AI assistant helping with GitLab operations.

        Context: $AI_FLOW_CONTEXT
        Task: $AI_FLOW_INPUT
        Event: $AI_FLOW_EVENT

        Please execute the requested task using the available GitLab tools.
        Be thorough in your analysis and provide clear explanations.

        <important>
        Please use the glab CLI to access data from GitLab. The glab CLI has already been authenticated. You can run the corresponding commands.

        If you are asked to summarize an MR or issue or asked to provide more information then please post back a note to the MR/Issue so that the user can see it.
        You don't need to commit or push up changes, those will be done automatically based on the file changes you make.
        </important>
        "
      - git checkout --branch $CI_WORKLOAD_REF origin/$CI_WORKLOAD_REF
      - echo "Checking for git changes and pushing if any exist"
      - |
        if ! git diff --quiet || ! git diff --cached --quiet || [ --not --zero "$(git ls-files --others --exclude-standard)" ]; then
          echo "Git changes detected, adding and pushing..."
          git add .
          if git diff --cached --quiet; then
            echo "No staged changes to commit"
          else
            echo "Committing changes to branch: $CI_WORKLOAD_REF"
            git commit --message "Codex changes"
            echo "Pushing changes up to $CI_WORKLOAD_REF"
            git push https://gitlab-ci-token:$GITLAB_TOKEN@$GITLAB_HOST/gl-demo-ultimate-dev-ai-epic-17570/test-java-project.git $CI_WORKLOAD_REF
            echo "Changes successfully pushed"
          fi
        else
          echo "No git changes detected, skipping push"
        fi
    variables:
      - ANTHROPIC_API_KEY
      - GITLAB_TOKEN_NAMI
      - GITLAB_HOST
    ```

        </details>

Du kan henvise til [GitLab CLI agents docs](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/) for detaljerede instruktioner.

### Eksempler

Her er nogle eksempler på, hvordan du kan bruge Nami i GitLab.

:::tip
Du kan konfigurere til at bruge en anden udløsersætning end `@nami`.
:::

- **Forklar et problem**

  Tilføj denne kommentar i et GitLab-problem.

  ```
  @nami explain this issue
  ```

  Nami vil læse spørgsmålet og svare med en klar forklaring.

- **Løs et problem**

  I et GitLab-nummer skal du sige:

  ```
  @nami fix this
  ```

  Nami vil oprette en ny branch, implementere ændringer og åbne en Merge Request med ændringer.

- **Gennemgå Merge Requests**

  Efterlad følgende kommentar til en GitLab-Merge Request.

  ```
  @nami review this merge request
  ```

  Nami vil gennemgå din Merge Request og give feedback.
